# 🧮 Simple Calculator

A clean, modern, and responsive calculator built using **HTML, CSS, and JavaScript**. It provides a simple interface for performing everyday mathematical calculations with both mouse and keyboard support.

## ✨ Features

- ➕ **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
- 📊 **Percentage Calculation:** Calculate percentages easily.
- ➖ **Positive/Negative Toggle:** Change the sign of numbers.
- 🔢 **Decimal Support:** Perform calculations with decimal numbers.
- ⌫ **Backspace:** Delete the last entered digit.
- 🧹 **All Clear (AC):** Reset the calculator instantly.
- ⌨️ **Keyboard Support:** Perform calculations using your keyboard.
- 🕒 **Calculation Display:** View the pending operation on the display.
- ⚡ **Error Handling:** Handles division by zero.
- 🎨 **Modern UI:** Sleek dark theme with orange accents.
- 📱 **Responsive Design:** Works across different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/ishika588/Simple-Calculater.git
```

### 2. Navigate to the Project Folder

```bash
cd Simple-Calculater
```

### 3. Run the Application

Open the `index.html` file in your preferred web browser.

**No additional installations or dependencies are required.**

## ⌨️ Keyboard Shortcuts

| Key | Action |
|---|---|
| 0–9 | Enter numbers |
| + | Addition |
| - | Subtraction |
| * or X | Multiplication |
| / | Division |
| Enter or = | Calculate result |
| Esc or C | Clear calculator |
| Backspace | Delete last digit |
| % | Percentage |
| . or , | Decimal point |

- Division: `10 ÷ 5 = 2`

- Decimal calculations: `10.5 + 2.5 = 13`
